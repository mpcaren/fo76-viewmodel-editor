    Offset

    X = right, Y = forward, Z = up, in game units. The offset moves the arms and gun together in every hip-fire clip (idle, walk, run, fire, reload, equip…). Aiming down sights is never changed, so sights stay lined up.

    Preview parts

    Parts only change what the preview shows; every mod of a weapon uses the same animations.
